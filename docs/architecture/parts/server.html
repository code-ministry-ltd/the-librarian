Architecture overview

One process serves agents and the dashboard on separate listeners

The agent port can be published to the network. The admin API is on a second listener that is never published, so reaching it requires already being inside the box or the container network.

The public listener has a short route table

Route Job
/mcp The 8 agent verbs
/transcript Receives conversation deltas
/import, /import/plan, /import/policy Past-conversation import
/journal.md The journal window injected at session start
/ingest Saves an article or file as a reference
/healthz, /primer.md Status and the primer, ahead of the origin check

Source: packages/mcp-server/src/http/routes.ts:587-604. The internal listener defaults to 127.0.0.1:3840 (packages/mcp-server/src/bin/http.ts).

Why two listeners instead of an admin token?
Decision
Serve /trpc/* on an internal-only listener and drop the admin token as a network gate.
Constraint
The admin API includes calls that return decrypted secrets, and it has no need to be on the network.
Rejected
Keeping tRPC public behind a token: defence by token over a surface that needn't exist.
Cost accepted
A code change to split the HTTP listener.
Source
ADR 0008 (observed)
Why a fixed set of 8 verbs?
Decision
Agents get exactly recall, remember, flag_memory, store_handoff, list_handoffs, claim_handoff, search_references and journal.
Constraint
Every harness has to mirror the surface, so it is pinned by the tool-registry test and the healthcheck.
Rejected
The earlier larger surface of 9 advertised and 3 internal tools.
Cost accepted
Adding a verb is a deliberate, ADR-level decision.
Source
ADR 0007, ADR 0016 (observed)

Seven serial timers run all background work

Backup, intake, grooming, flag grooming, the transcript sweep, journal compaction and usage stats each run on a serial scheduler, so a job never overlaps itself. Each job checks its own settings on every tick, so switching one on or off needs no restart.

Source: packages/mcp-server/src/librarian-server.ts:515-690. Any timer can be disabled by setting its interval to 0.

Why polling timers rather than events?
Decision
Each job polls and decides for itself whether it is due.
Constraint
Reason not recorded as a single decision. The code comments give one benefit: toggling a job or editing its schedule takes effect on the next poll with no restart.
Rejected
Not recorded. ADR 0011 separately rejects a general event bus as a plugin mechanism.
Cost accepted
Work waits for the next tick.
Source
librarian-server.ts comments (observed); overall reason unknown

Extensions are compiled in through named seams

createLibrarianServer is the single composition root. A plugin is an imported object that can add MCP tools, tRPC routers and HTTP routes, and can replace the auth, vault-routing and actor-display providers.

Why build-time plugins?
Decision
A build-time plugin API behind one composition root, with named seams.
Constraint
A private overlay needs to reach recall ranking and write routing without forking the open-source repo.
Rejected
Fork and merge (the merge tax compounds); publishing the internals; sidecar or proxy composition; dynamic plugin loading (supply-chain surface); a general event bus.
Cost accepted
The seam types become a compatibility promise.
Source
ADR 0011 (observed)

Known limits

The server assumes it is the only writer of the vault: handoff claims are atomic only within that single process (markdown-handoff-store.ts:107-112). Running two servers on one vault is not a supported shape.
